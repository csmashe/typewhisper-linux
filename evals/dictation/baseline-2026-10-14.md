## What to fix or compare next

The current LLM cleanup path runs Light cleanup before the LLM. That pass resolves backtracks and can remove the correction marker before the model sees it. For the canceled-send case, the fake echo run already produced the same wrong send-and-save text. Investigate preserving correction context in the LLM input while retaining Light as the fallback output. Live and final cleanup must use the same prepared-input contract.

The existing cleanup prompt does not receive an app-specific writing instruction from these style presets. Compare a prompt with explicit punctuation and finished-prose expectations, then add profile context to the same live/final path if needed. Keep quoted content, uncertain intent, and unfinished thoughts protected.

Treat the filename case as a separate capability check. Dictionary terms are configured, but this route skips audio-token rescoring, and a term is not a find-and-replace correction. Test a declared filename alias or developer formatter behavior before blaming the LLM alone.

Review the 30 outputs before approving a new prompt. Keep the user labels separate from these observations. No additional paid judge run has been made.
