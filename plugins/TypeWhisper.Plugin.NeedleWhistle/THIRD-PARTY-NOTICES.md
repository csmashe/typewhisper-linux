# Third-party notices

The Needle command-line runtime and Whistle model are downloaded on demand from the official Cactus Compute Hugging Face repositories. They are not included in this plugin archive.

- Needle runtime: [Cactus-Compute/needle3](https://huggingface.co/Cactus-Compute/needle3), licensed under Apache-2.0.
- Whistle model: [Cactus-Compute/whistle](https://huggingface.co/Cactus-Compute/whistle), licensed under Apache-2.0.
- Source and runtime documentation: [cactus-compute/needle](https://github.com/cactus-compute/needle).

The plugin pins the Linux x86-64 runtime and Whistle model to immutable Hugging Face revisions and verifies each downloaded file with SHA-256 before use.
