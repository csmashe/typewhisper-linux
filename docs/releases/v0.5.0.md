# TypeWhisper Linux v0.5.0

TypeWhisper Linux 0.5.0 is a port-forward release. Everything below was
brought over from the upstream project and adapted to work on Linux —
new provider plugins, new dictation and post-processing features, and a
batch of supporting refactors. There is no Linux-original functionality
in this release; each item originated upstream and was updated for the
Linux build.

## New Features

- Added the xAI / Grok plugin, providing LLM, speech-to-text, and
  text-to-speech support.
- Added the Supertonic TTS local plugin with on-demand asset download
  and ONNX-based synthesis.
- Added the Smallest AI Pulse transcription plugin.
- Added the Reson8 transcription plugin, supporting both prerecorded and
  streaming (WebSocket) audio, custom model fetching/selection, API-key
  validation, a configurable base URL and auth header, and en/de
  localization.
- Extended the OpenAI plugin with a ChatGPT integration: OAuth login and
  text-to-speech support.
- Extended the OpenRouter plugin with both LLM and transcription
  support.
- Added GPU acceleration with auto-resolve, integrated across the
  compute-backed plugins so the best available backend is selected
  automatically.
- Added Industry Preset support, with bundled TermPacks and an
  onboarding UI for selecting a preset.
- Added a draggable dictation overlay with a user-defined custom screen
  position on Linux (building on the configurable overlay widgets from
  0.4.0).
- Added side-specific single-modifier hotkeys with collision detection,
  so the left and right variants of a modifier can be bound
  independently.
- Added a configurable auto-hide delay for the dictation feedback
  bubble.
- Added a manual-only flag (`IsManualOnly`) for prompt actions, plus two
  direct prompt-action hotkeys (B12 and B13).
- Added temperature settings for LLM chat completions, with dedicated
  handling for GPT-5 / o-series models.
- Added an online batch live-transcription preview option for Linux,
  with a fallback to the streaming preview when the batch result comes
  back empty.
- Added CLI auto-discovery and a dictation HTTP API with session
  polling, extending the single-instance CLI introduced in 0.4.0.
- Added a `RequireLlmSuccess` flag to the post-processing pipeline so a
  failed LLM step can block insertion instead of silently falling
  through with un-processed text.
- Added a Linux dictation readback language policy with a TTS fallback.

## Improvements

- Added `LinuxDictationFinalTextPolicy`, a raw-text selection policy that
  strips automatic ellipses and repeated phrases from final dictation
  output, with unit-test coverage.
- Taught `AppFormatterService` to strip HTML formatting for Outlook and
  Thunderbird so pasted dictation lands as plain text in those clients.
- Hardened `PromptProcessingService` to frame user input as inert data
  before sending it to the LLM, reducing prompt-injection risk from
  dictated content.
- Made `DictationOrchestrator` track partial-transcription status and
  default the `PartialText` property so partial state is always
  well-defined.
- Updated `DictationSectionViewModel` to handle compute-backend changes
  cleanly when GPU acceleration is toggled.
- Pointed the Linux GUI shortcut commands at the CLI process path so the
  desktop entry and shortcuts drive the same single-instance CLI.
- Updated the Deepgram and OpenAI plugins to handle streaming sessions
  correctly.
- Reorganized `ProfilesSectionViewModel` for readability.
- Rewrote the Soniox plugin (1.0.2) around an async upload/poll flow
  (upload file, create transcription, poll, fetch transcript, clean up),
  with token-to-segment parsing with timing info, improved API-key
  handling and validation, and richer error reporting; dropped the unused
  `selectedModel` setting.
- Added `DictationInsertionTextFormatter`, which pads inserted text with a
  trailing space when needed, and wired `DictationOrchestrator` to use it
  so consecutive dictations are no longer concatenated.
- Reworked the history view to load entries in pages with lazy-load on
  scroll, and fixed the timeline so it fills the available height and
  scrolls the full history.

## Fixes

- Fixed a scroll issue with large partial text in the dictation view.
- Fixed a playback-stop hang: the audio stream is now stopped and
  disposed off the playback lock, so stopping a history recording no
  longer freezes the app.
