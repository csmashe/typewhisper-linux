# TypeWhisper Linux v0.7.0

TypeWhisper Linux 0.7.0 is the profiles-and-hotkeys release. Building on the
0.6.0 streaming work, it makes profiles first-class: each profile can own a
global hotkey that either dictates straight into that profile or runs its
prompt against the current selection. It also adds deterministic spoken-command
normalization (line breaks and punctuation) ahead of any LLM step, refreshes
provider model lists live when a dropdown opens, and finishes the GNOME/Mutter
startup-notification handshake so the launch cursor clears promptly.

## New Features

- Added per-profile hotkeys. A profile can now bind its own global shortcut with
  a behavior: **Start Dictation** routes a dictation session straight into that
  profile's context, or **Process Selected Text** runs the profile's prompt
  against the current selection. The profile editor exposes an editable hotkey
  chord and a behavior dropdown, and bindings are wired up on startup and re-bound
  when profiles change.
- Profile hotkeys are collision-checked against existing canonical shortcuts so a
  profile chord can't silently shadow another binding. Hotkey-triggered dictation
  is pinned to the chosen profile via a forced-profile path through the
  `DictationOrchestrator`, bypassing normal context matching.
- Hotkey-only profiles no longer act as the global ambient fallback, so adding a
  shortcut-driven profile doesn't change which profile wins for untargeted
  dictation.
- Added deterministic spoken-line-break normalization. Spoken "new line" and
  "new paragraph" commands are converted into real line breaks before the text
  reaches the LLM or gets inserted (`NormalizeSpokenLineBreaks`).
- Added spoken-punctuation normalization. Phrases like "question mark" and
  "exclamation point/mark" are converted to `?` and `!` deterministically before
  LLM processing, preserving surrounding whitespace and formatting.
- Added live model-catalog refresh. The SDK gained `IModelCatalogProvider` for
  plugins that expose dynamic model lists, and model/provider dropdowns in the
  Dictation, Plugins, Profiles, and Prompts sections now re-poll the active
  provider when opened so newly available models appear without restarting. The
  OpenAI-compatible plugin implements it; `PluginManager` drives a debounced,
  side-effect-free refresh.
- Seeded a Wispr-Flow-style cleanup setup on first run: an **Auto Clean Up Text**
  prompt and an **Auto Format** profile bound to `Ctrl+Alt+E`, shipped seeded but
  disabled so you can point the cleanup at your own LLM and turn it on.

## Improvements

- Completed the Linux startup-notification handshake. Mutter's launching/busy
  cursor now ends promptly when the main window maps, and on toggle and
  already-running quick-exit paths that never map a window, improving launch UX
  on GNOME/XWayland.
- Added `StartupWMClass=typewhisper` to the generated desktop entries so the
  shell associates the launch with the running window.
- The install script now separates the binary install directory from the user
  data directory and warns about leftover old installs.
- Added a golden prompt-input-framing contract test so the exact input format
  fed to fine-tuned cleanup models stays stable.

## Fixes

- Tightened hotkey press/release handling in the shortcut dispatcher and matcher,
  deduplicating repeated press/release events introduced by the per-profile
  hotkey paths.

## Not Ported From Windows

- Windows release channels and Velopack update-channel controls are not part of
  this Linux branch; the Linux app checks GitHub Releases for updates but installs
  them manually.
- Windows-specific workflow automation and packaging changes remain Windows-only.
