# TypeWhisper Linux v0.7.5

TypeWhisper Linux 0.7.5 is a small fix release for dictation into
`gnome-terminal` (and other client-server terminals). On those terminals a
dictated transcript was delivered as a synthesized Ctrl+V — which a terminal
doesn't interpret as paste — so nothing appeared. Direct typing into terminals
already existed; this release just makes the terminal-detection recognize the
process name a client-server terminal actually reports. Linux Mint / Cinnamon
is now a tested setup. Nothing else changes.

## Fixes

- **Dictation into `gnome-terminal` now types instead of pasting.** Smart
  `Auto` insertion already types directly into terminals (a synthesized Ctrl+V
  is bound to readline's quoted-insert, not paste), but `gnome-terminal` and
  `mate-terminal` use a client-server model: the focused window is owned by
  `gnome-terminal-server`, and Linux truncates the process name read from
  `/proc/<pid>/comm` to 15 bytes, so the app actually sees `gnome-terminal-`.
  The terminal check only matched the exact name or names ending in
  `-terminal`/`term`, so the trailing characters made it fall through to
  clipboard paste — which produced nothing in the terminal. Terminal detection
  now matches `terminal` as a substring, so `gnome-terminal-server`,
  the truncated `gnome-terminal-`, `mate-terminal-s`, and the existing
  `*-terminal` names are all recognized and dictation types into them. An
  explicit per-app **Clipboard paste** override still wins for users who want it.

## Not Ported From Windows

- Windows release channels and Velopack update-channel controls are not part of
  this Linux branch; the Linux app checks GitHub Releases for updates but installs
  them manually.
- Windows-specific workflow automation and packaging changes remain Windows-only.
