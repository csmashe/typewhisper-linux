# TypeWhisper Linux v0.7.1

TypeWhisper Linux 0.7.1 is a Wayland text-insertion fix release. It corrects the
type-vs-paste decision so dictation types directly into the focused app on
GNOME and KDE Wayland instead of falling back to a clipboard paste that
terminals reject and Claude Code reinterprets as an image paste. It also stops
recommending xdotool to Wayland users, where it cannot type into native Wayland
windows.

## Improvements

- The "automatic paste" setup hint on Wayland no longer suggests installing
  xdotool. xdotool is XWayland-only and cannot type into native Wayland apps, so
  the hint now recommends wtype or ydotool instead.

## Fixes

- Fixed Wayland dictation falling back to clipboard paste when xdotool happened
  to be installed. The direct-typing decision for an unidentified target now
  keys off having an actually-usable Wayland typing backend — ydotool (which
  injects below the compositor and works everywhere) or wtype on wlroots
  compositors — instead of the mere absence of xdotool. A stray xdotool pulled
  in by an unrelated package no longer forces a Ctrl+V paste, so dictation types
  correctly into terminals (Ghostty, kitty, …), Claude Code, vim, and other apps
  on GNOME/KDE Wayland when ydotool is set up.

## Not Ported From Windows

- Windows release channels and Velopack update-channel controls are not part of
  this Linux branch; the Linux app checks GitHub Releases for updates but installs
  them manually.
- Windows-specific workflow automation and packaging changes remain Windows-only.
