# TypeWhisper Linux v0.2.0

TypeWhisper Linux 0.2.0 grows the port into a full-featured X11 desktop
application. It adds the prompt palette, live partial transcripts, the
on-screen dictation overlay, file transcription, and the HTTP control API on
top of a hardened Linux platform layer.

## New Features

- Added the prompt palette — a hotkey-triggered overlay for running prompt
  actions against dictated or selected text.
- Added live partial transcripts that stream into the UI while you speak.
- Added the on-screen dictation overlay, matching the Windows edition.
- Added File transcription and Recorder sections (replacing the earlier Audio
  and Models sections).
- Added the HTTP API for controlling TypeWhisper and querying its state.
- Added a selectable compute backend (CPU or CUDA) for local transcription.
- Added vocabulary boosting, term packs, and snippet tag filtering.
- Added sound feedback, silence-based auto-stop, and system-command
  availability checks.
- Added Whisper mode and live profile switching in the dictation UI.
- Added Advanced and Appearance settings sections; reworked the About and
  Prompts pages.
- Added plugin model deletion, plus a plugin registry with session-audio
  management and playback.
- Added speech-feedback and memory services.
- Added Linux install / uninstall scripts and a Linux-focused README.

## Improvements

- Adopted FluentIcons for sidebar navigation.
- Refactored the audio recording service and Hybrid hotkey behavior.

## Fixes

- Fixed hotkey collision and conflict handling.
- Fixed plugin activation / deactivation, including activation concurrency.
- Fixed dictation error handling and HTTP CORS handling.

## Security

- Hardened the Linux platform layer and plugin system.
