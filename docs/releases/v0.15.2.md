# TypeWhisper Linux v0.15.2

TypeWhisper Linux 0.15.2 brings **HTTP API and CLI parity with the Mac
client**, **provider plugin alignment** for OpenAI, OpenAI Compatible,
OpenRouter and ElevenLabs, and a set of **small correctness fixes** in shared
code. All of it was ported and adapted from the upstream 2026-09-14 baseline,
with Linux integration, review fixes, and behaviour changes noted below where
the Linux port deliberately differs.

Highlights include subtitle output and per-segment translation from the API,
model load/unload/delete over the API and CLI, dictation and history commands
in `typewhisper-cli`, Azure OpenAI deployments and the Responses API through
OpenAI Compatible profiles, and ElevenLabs live sessions that no longer cut
words mid-utterance.

Two behaviour changes matter when upgrading: **OpenAI Compatible endpoints no
longer send `temperature: 0.1` by default**, and **`typewhisper-cli` now uses
distinct exit codes** for usage errors, an unreachable app, and API failures.
Both are described in the notes below.

## New Features

- **Subtitle and plain-text output from the API.** `response_format` accepts
  `text`, `srt`, and `vtt` in addition to `json` and `verbose_json`. Subtitle
  formats are built from the engine's segment timestamps and answer `422` when
  an engine produced none. Cue times are rounded to milliseconds so cues never
  overlap by a rounding error.
- **Translated subtitle segments.** With `target_language` set, the segments of
  `verbose_json`, `srt`, and `vtt` responses are translated too. LLM providers
  receive them in bounded batches (at most 32 segments or 8,000 characters) and
  must return every segment; a misaligned reply fails the request with `502`
  rather than pairing text with the wrong cue. The local Marian model falls
  back to per-segment calls. `language` then reports the output language.
- **Dictionary corrections on segments.** Timed segments receive the same
  dictionary corrections as the full text, before translation. The new
  `apply_corrections` option (JSON field, form field, or `x-apply-corrections`
  header) switches corrections off for one request.
- **More API routes.** `GET /v1/capabilities` lists routes, formats, and limits
  for feature detection; `GET /docs` serves a built-in HTML reference and is the
  only route without a token; `/v1/rules` and `/v1/rules/toggle` alias the
  profile routes. A known path with the wrong method answers `405` with an
  `Allow` header instead of `404`.
- **Model control over the API.** `POST /v1/models/load`, `POST
  /v1/models/unload`, and `DELETE /v1/models` load, unload, and delete engine
  models without blocking on the model lock: a busy manager answers `409`, as
  does a delete of the selected or loaded model, or an unload through another
  engine.
- **CLI parity.** `typewhisper-cli` gains `history [search <query>]`, `last`,
  `dictation start|stop|status|result`, `models list|load|unload|delete`,
  `--no-corrections`, raw `text`/`srt`/`vtt` output, and implicit stdin when no
  file is given. `Ctrl+C` interrupts every command cleanly. Exit codes are now
  `0` success, `1` usage error or `Ctrl+C`, `2` app not running or timed out,
  and `3` API error; earlier releases exited `1` for every failure. The CLI
  stays a single trimmed file; `--port`, `--profile`, and `--dev` from upstream
  were not ported because the Linux CLI is socket-only.
- **OpenAI Compatible: Responses API and request options.** Each endpoint and
  profile chooses Chat Completions or Responses, a Responses reasoning effort,
  and a temperature mode. **Provider default now sends no `temperature`**;
  earlier releases always sent `0.1`. Set the Custom mode to `0.1` to keep the
  old behaviour. Responses replies in `failed` or `cancelled` state are
  rejected, and the nested `text.value` reply shape is read.
- **OpenAI Compatible: Azure deployments.** An optional API version is appended
  to every request of a profile, and a deployment-scoped transcription endpoint
  uses Azure's `/deployments/{model}/audio/transcriptions`. Requests to Azure
  OpenAI hosts carry both `Authorization: Bearer` and `api-key`. Versioned or
  deployment-scoped transcription asks for `json`, which Azure accepts, so those
  routes return no segment timestamps.
- **OpenAI Compatible: realtime transcription.** Endpoints and profiles gain a
  transcription mode (automatic, batch, realtime) and a realtime protocol
  (automatic, live transcribe, realtime whisper). Automatic streams the
  `gpt-live-transcribe` and `gpt-realtime-whisper` families over the realtime
  WebSocket; Realtime forces it for custom deployment aliases. Realtime
  endpoints refuse translation up front and forward every language hint.
- **OpenRouter segments and languages.** OpenRouter transcription reports
  per-segment timestamps and a 57-language Whisper set per model, and credits
  prefer `limit_remaining`.
- **Provider language lists.** Deepgram exposes the documented Nova-2 and
  Nova-3 language sets for the selected model, and Groq exposes the Whisper
  list. An explicitly selected language the provider does not support now fails
  before upload with a clear message listing at most twelve codes. A regional
  tag such as `de-DE` folds to its base language when the provider lists only
  base codes (Groq); lists with regional entries (Deepgram) stay strict because
  their regions select distinct models.

## Fixes

- **ElevenLabs live sessions commit at pauses.** The realtime session now
  drives commits itself instead of relying on the provider's voice activity
  detection, which split words mid-utterance during long speech. After 20
  seconds of audio the next 200 ms pause closes a segment; 32 seconds without
  any pause ends the live session so the complete recording is transcribed
  over REST. Two improvements over upstream: the pause is detected per sample
  and the outbound message is cut at the pause, so detection does not depend on
  chunk alignment, and pending commits are counted so a late acknowledgement
  cannot end the session before the tail is transcribed.
- **ElevenLabs keyterms and routing.** Keyterms are bounded to the provider
  limits (1,000 entries, under 50 characters, at most 5 words) through the
  dictionary budget. Automatic mode uses the complete recording when keyterms,
  audio events, or a speaker count are set. A key restricted to `user_read`
  reports "could not verify" instead of "invalid key", and an unreachable API
  reports a connection problem rather than rejecting the key.
- **OpenAI plugin routing and sign-in.** Model families match exactly or with a
  `-` suffix, fine-tuned ids unwrap to their base for routing, Astra models
  route correctly, and non-chat families are excluded from the text-model list.
  ChatGPT sign-in reads the callback state before the error field, so a
  declined consent surfaces as an authentication failure with a clear message.
- **Reasoning-only replies are errors.** The shared OpenAI-style chat helper
  reads typed content parts and refuses a reply that contains only reasoning,
  which fixes empty results from reasoning models on every OpenAI-style
  provider. When a server rejects `max_tokens` and names
  `max_completion_tokens` (or the reverse), the request is retried once with
  the other parameter.
- **Translation requests omit the source language.** The shared transcription
  helper adds the `language` field only on transcription requests, which covers
  Groq, OpenAI, OpenAI Compatible, and Qwen3 STT. Groq rejects translate on
  `whisper-large-v3-turbo` before any upload with a localized message instead
  of a provider `400`.
- **Newline corrections no longer leave a stray period.** When a dictionary
  correction expands to a line break only, the recognizer's trailing period is
  consumed with it, including after CRLF or several line breaks. Mid-text
  periods and regex corrections are untouched.
- **Atomic Obsidian notes.** A new note is staged in a temporary sibling,
  flushed, and published without replacing an existing name, using hard links,
  `renameat2`, or an exclusive copy depending on what the filesystem supports,
  so vaults on exFAT, SMB, or FUSE still save. A crash mid-write can no longer
  leave a truncated note for Obsidian or a sync client.
- **SherpaOnnx models really unload.** The plugin never released its Parakeet
  or Canary recognizer on unload, so idle auto-unload, shutdown, and the new
  unload route reported success while the model stayed resident. It now
  disposes the recognizer under the plugin lock and keeps the selected model
  for the next load.

## Plugin SDK

- `OpenAiTranscriptionHelper.TranscribeAsync` gains an `endpointOverride` and
  `requestHeaders` overload for deployment-scoped routes and extra headers; the
  previous signature is kept as a forwarder for plugins built against the older
  SDK.
- `OpenAiChatRequestOptions` gains `RequestUri` and `RequestHeaders`, and the
  chat helper retries once on a rejected output-token parameter name.
- The OpenAI realtime WebSocket session and the Responses client moved to
  `plugins/Shared/OpenAi` and serve both OpenAI plugins with a configurable
  endpoint, headers, and protocol.

## Under the Hood

- **Route catalog.** A single `HttpApiRoutes` catalog with per-route
  descriptions drives dispatch, the `405` responses, `/v1/capabilities`, and
  the `/docs` page.
- **Non-blocking model operations.** `ModelManagerService` gains `Try*` methods
  that return an outcome instead of waiting on the model lock, which the API
  and CLI build on.
- **Regression coverage.** Tests cover segment translation batching and
  misalignment, subtitle validation, the route table and method handling,
  model control outcomes, CLI exit codes and cancellation, ElevenLabs manual
  commits and key checks, OpenAI Compatible request shapes, and the regional
  language fold.

## Notes

- **CLI exit codes changed.** Scripts that tested for exit code `1` on any
  failure should test for non-zero, or for `2` and `3` specifically. The
  package smoke test was updated accordingly.
- **The `/docs` route needs no token.** It serves a static reference page and
  is still limited by the same origin and loopback checks as every other route.
- **ElevenLabs edge case.** Stopping within 300 ms of a periodic commit makes
  the provider throttle the tail commit; that recording is transcribed over
  REST with the same result, only later.
- All new interface strings are translated across **English, German, Spanish,
  and Russian**.
- **Included scope.** PRs #93 (Batch A), #94 (Batch B), and #95 (Batch C) of
  the 2026-09-14 upstream port. Recorder pause/resume, read-aloud, history
  multi-select, streaming detected language, and Parakeet CTC vocabulary
  boosting are approved for a later release.
