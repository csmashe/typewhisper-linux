# TypeWhisper Linux v0.3.0

TypeWhisper Linux 0.3.0 extends the app beyond what the Windows edition
shipped. It adds batch file transcription with a watch folder, text-to-speech
output, the ElevenLabs streaming plugin, the CLI installer, and richer HTTP
API endpoints — plus experimental Wayland text insertion via `wtype`.

## New Features

- Added batch file transcription and a watch folder that transcribes new files
  automatically.
- Added text-to-speech provider integration with Linux system-voice support.
- Added recent transcriptions with customizable hotkeys for quick re-insertion.
- Added the ElevenLabs plugin for cloud transcription with real-time
  streaming.
- Added a CLI installation service that installs a `typewhisper` command, with
  usage examples surfaced in General settings.
- Added translation and dictionary-management endpoints to the HTTP API.
- Added prompt support for transcription plugins.
- Added the ability to cancel an in-progress dictation with the `Escape` key.
- Added auto-paste and clipboard management in the text-insertion service.
- Added experimental Wayland text insertion via `wtype`.
- Added project governance: issue/PR templates, a security policy, and a
  plugin smoke-test CI workflow.

## Improvements

- Expanded the README to cover the new transcription, profile, and
  voice-command features.
- Improved error handling and state management in the ElevenLabs and Groq
  plugins.

## Fixes

- Fixed HTTP client timeout and error handling.
- Fixed Linux process execution under concurrent errors and timeouts.
- Fixed the word-count calculation in transcription records.
- Fixed active-window detection and dictation handling on Linux.
