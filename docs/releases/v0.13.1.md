# TypeWhisper Linux v0.13.1

TypeWhisper Linux 0.13.1 is a **hardening release**. It carries the result of a
full-codebase audit — every section of the app, the plugin SDK, all 30-odd
plugins, the CLI, the packaging scripts, and the test suite. It closes the
audit's entire remaining backlog — over 150 tracked findings, from privilege and
secret-handling problems down to silent transcript corruption and data loss —
along with the follow-ups discovered while fixing them.

Three things in it are user-visible enough to call features rather than fixes:
**`typewhisper-cli` now ships in every package** (and it no longer trusts
whoever answers the loopback port),
**Gladia, Voxtral, and long Google Cloud STT recordings actually work**, and
**you can now revoke the keyboard access TypeWhisper asked for** without
uninstalling anything.

Target-app correction learning, the headline of 0.13.0, is unchanged in
behaviour. Its cold-start focus bootstrap and its AT-SPI error classification
were hardened, and a failed Undo now tells you instead of failing silently.

## New Features

- **`typewhisper-cli` ships in every Linux package.** The tarball, AppImage,
  `.deb`, and `.rpm` all carry the CLI now, installed atomically and verified
  against its own `--version` output; the `.deb` and `.rpm` expose it on `PATH`
  as `/usr/bin/typewhisper-cli`. It was renamed from `typewhisper` because two
  incompatible programs previously claimed that command, and the in-app
  **Install CLI** button installs the launcher to `~/.local/bin/typewhisper-cli`
  and refuses to overwrite a launcher it doesn't own.

- **The CLI and the local API now authenticate each other.** Bearer-token
  authentication on the TCP endpoint is not new, but it only proved the *client*.
  The CLI trusted whichever process accepted plain HTTP on the discovered
  loopback port — so if the app wasn't running, another local account could bind
  the free port and collect your bearer token and your audio. The API is now
  served by Kestrel over both the existing bearer-authenticated TCP endpoint
  (`curl` keeps working unchanged) and an owner-only `api.sock` that validates
  `SO_PEERCRED` before parsing a single HTTP byte. The CLI itself is Unix-socket
  only — `--port` is gone — and it checks the *server's* UID before anything
  leaves the process.

- **Gladia batch transcription works.** The v2 upload / initiate / poll protocol
  is implemented, replacing the 0.13.0 stopgap that just failed fast with
  "unsupported".

- **Voxtral works.** It now speaks Mistral's documented transcription API
  directly — its own request and response handling, with segment timestamps
  requested explicitly — instead of being forced through generic
  OpenAI-compatible handling, and a translation request is rejected outright.
  (The model-id correction and the honest no-translation capability flag shipped
  in 0.13.0.)

- **Google Cloud STT transcribes recordings longer than 60 seconds**, by cutting
  them into sequential sync requests of at most 55 seconds each, placed at the
  quietest window near the boundary to reduce mid-word splits. (True long-running
  recognition needs a GCS bucket and OAuth, which an API-key-only plugin can't
  reach.)

- **Keyboard access can be revoked from the app.** Shortcuts gains a **Revoke
  keyboard access** action that removes the udev rule and the `input`-group
  membership TypeWhisper's own grant record accounts for, plus a focused-only
  mode that turns raw keyboard reads off entirely and tells you if a rule is
  still installed. Membership added by hand — or by a TypeWhisper old enough not
  to have recorded it — can't be attributed and is left for you to remove.

- **Desktop integration tells you when it has gone stale.** Change your hotkey
  or activation mode after installing a GNOME/KDE/Hyprland/Sway shortcut and
  you now get a warning plus a **Refresh desktop integration** action, instead
  of a silently authoritative old binding.

- **The managed CUDA library path can be removed** from the CUDA environment
  panel, which takes out only TypeWhisper's own shell fragments and environment
  file.

## Security

- **Secrets are protected by a real key.** The AES-GCM key guarding plugin
  secrets, the HTTP bearer token, and legacy API-key fields was PBKDF2 over your
  username and `$HOME` with a constant salt — reproducible by anyone holding the
  settings files, so the at-rest encryption was obfuscation. Secrets now use
  AES-256-GCM under a random 32-byte key at `<base>/secret-protection.key`
  (mode `0600`, created atomically; an existing key is never replaced, though a
  deleted one is regenerated and cannot recover what the old key protected) in a versioned
  `TWSP v2` envelope. A startup migration re-encrypts legacy values file by
  file, atomically and idempotently; values that can't be authenticated fail
  closed to null rather than passing ciphertext along, and you are told which
  ones to re-enter. Backups still contain your secrets (encrypted) and never the
  key file, and a backup is refused outright while any known secret can't be
  decrypted.

- **Ownership checks now cover every installer-owned file.** 0.13.0 already made
  the `ydotool` and evdev/udev setup paths refuse foreign root-owned files and
  symlinks, and already required proven absence of a seat manager before the
  `input`-group fallback; those safeguards are unchanged. What this release adds
  is the same treatment for everything else TypeWhisper writes outside its own
  data directory — the KDE integration, the autostart entry, the CLI launcher,
  and the managed CUDA shell fragments are each guarded by an evidence-gated
  ownership transaction before they overwrite or delete anything, and compositor
  config writes no longer replace a symlinked dotfile with a regular file.

- **Webhook authorization headers are stored as host secrets** instead of
  plaintext that the UI echoed back.

- **Recordings and generated speech are owner-only.** The recordings directory
  is created at mode `0700` and TTS plugins no longer leave world-readable WAVs
  behind.

- **Obsidian writes are contained to the vault.** A configured subfolder or
  daily-note path can no longer escape it, and concurrent actions claim their
  target atomically instead of overwriting a whole note.

- **Downloads and plugin compatibility fail closed.** An unverifiable download
  is rejected rather than published, a truncated non-resumable download can no
  longer masquerade as complete, and a plugin whose minimum-host version can't
  be parsed is refused instead of admitted.

- **The local API can't be used to amplify memory.** Concurrent uploads are
  bounded, and a restore archive that expands far beyond a plausible settings
  backup is cancelled with an explanation — enforced on the bytes actually
  decompressed into the staging area, not on the sizes the archive declares.

## Reliability and Hardening

### Hotkeys and desktop integration

Installed desktop shortcuts now honour the selected recording mode, `Meta` stays
`Meta` in the GNOME, Hyprland, and Sway writers instead of being rewritten to
`Alt`, hotkey reconciliation is order-independent and revives bindings that were
previously rejected, and the prompt and profile editors validate a binding
before saving it. Modifier state no longer desynchronizes across multiple
keyboards or a dropped event stream, dictation release uses the binding and mode
that were live at press time, selection workflows wait for the triggering
modifiers to be released before synthesizing Copy, and every desktop-environment
helper command runs under a timeout instead of hanging forever. Read-modify-
replace writes to desktop files no longer discard concurrent changes.

### Text insertion, clipboard, and AT-SPI

The Wayland fallback chain no longer includes X11-only `xdotool` (which could
report success while typing nothing), a partial direct-typing failure no longer
replays the whole text through the fallback backend, and clipboard and injector
subprocesses are bounded by timeouts. Clipboard preservation now detects
non-text and rich formats and says so rather than silently restoring a lossy
copy, paste confirmation no longer accepts any unrelated same-app text change as
proof, Transform Selection sends Copy rather than SIGINT in terminals and
revalidates its target before replacing a selection, and learned-correction Undo
failures surface in the UI.

### Audio and feedback

Auxiliary capture features can no longer adopt and stop another feature's
recording, shutdown disposes the microphone after dictation cleanup rather than
before it, and start sounds and speech play before capture opens so they can't
be transcribed. Changing the microphone during preview takes effect for the next
dictation, a missing device identity no longer silently falls back to a stale
index and overwrites your preference, and the default-device watcher reconnects
when its subscription ends. Ducking no longer destroys per-channel balance
permanently and retries a restore it couldn't apply; downsampling no longer
aliases high-frequency content into the speech band; a hung sound player is
reclaimed; and tiling-WM users keep processing and terminal feedback after stop.

### Your data on disk

Every JSON state store in the app now goes through one transactional contract
(`AtomicJsonStore<T>`): write to a temp file, fsync, atomic replace, roll back on
failure, and never wipe the store because a load failed or was cancelled. Files
created for user output — recorder captures, watch-folder exports, transcript
sidecars — are allocated through a shared collision-safe allocator, so a
same-second filename can't overwrite an earlier recording, and sources are
deleted only after the export commits. Watch-folder fingerprints persist
transactionally with backup recovery, path identity is case-sensitive again (a
Linux directory really can hold `Notes.wav` and `notes.wav`), and a settings
restore is validated and staged while the app runs, then applied transactionally
at the next start — previously it was written live, where caches already holding
the old values could write them straight back over what you had just restored.

### Startup, shutdown, and the UI

Bootstrap is staged with per-stage boundaries and dependencies, so one failing
stage no longer silently skips everything after it, and watch-folder auto-start
waits for plugins and models to be ready. Plugin shutdown is bounded and never
skips disposal, so one misbehaving plugin can't hang exit. In the UI, History,
Dashboard, and About render timestamps in local time instead of UTC; plugin
dropdowns show exactly what Save will send; an ambient refresh no longer discards
unsaved plugin settings; third-party settings providers are isolated and
time-bounded so a throwing plugin can't take the settings page down; closing or
skipping onboarding cancels its work; switching language relocalizes labels,
option lists, and the tray menu; the hidden dictation overlay is parked offscreen
so it can't swallow clicks; and overlay Timer and Clock widgets tick on their own
rather than riding audio-level notifications.

### Plugins

Streaming providers no longer turn a mid-stream failure into a plausible-looking
partial transcript — AssemblyAI, Deepgram, and ElevenLabs propagate the fault,
the Claude/xAI/ChatGPT readers require a terminal event before reporting success,
and OpenAI realtime tracks pending audio with watermarks so a final utterance
can't be dropped. Every engine now declares which language selections it can
honour, and one it can't is refused with an explanation instead of being quietly
reinterpreted — Google Cloud STT no longer transcribes Auto as English, and an
explicit language is no longer silently ignored by Cloudflare ASR or the
non-Canary sherpa-onnx models; Gemma Local uses the model
the host asked for and stops forcing output back into the input language;
OpenAI-Compatible normalizes model selections against each server's catalog,
persists repaired profile IDs, and lets an API key be cleared; ChatGPT serializes
OAuth refresh behind a single-flight gate; xAI waits for the provider's readiness
event before sending audio; Sherpa honours cancellation around native decode and
CUDA provisioning; Smallest AI, Reson8, and Soniox tear down sockets under a
budget instead of hanging stop or shutdown; and OpenAI Vector Memory rolls back a
store that failed to persist.

### Plugin SDK contracts

These are the compatibility-relevant items, all landed here rather than left for
1.0: malformed successful responses are rejected instead of converted into empty
output, the transcription helper honours the plain-text response format it
advertises, additional provider objects are split into non-owning role
interfaces, selection identifiers have an enforced grammar, the event bus
delivers in order and non-reentrantly per subscription with latest-wins
coalescing of superseded non-terminal events, manifests are
authoritative for locality and category (so a plugin can no longer display a
false privacy badge), the manifest filename contract is single-sourced, and
`ActionResult`'s URL, duration, and icon finally reach the UI. Shared CUDA
libraries live under the configured asset root and their cache maintenance is
coordinated by a lock held outside the tree.

## Under the Hood

- **Consolidation.** Ten WebSocket streaming providers now share one session
  pump, every SSE stream is decoded by one WHATWG-compliant decoder with
  per-provider terminal policies, three 700-line PCM playback clones are replaced
  by host-owned playback, browsers are projected from one descriptor catalog,
  plugins from one machine-readable catalog, and `"auto"` string comparisons are
  replaced by a typed language selection with real error messages. Cancellation
  has a repository-wide origin contract, and installer-owned files are managed
  through evidence-gated ownership transactions.

- **A smaller install.** Bundling the CLI would have added 70 MB of duplicated
  .NET runtime; trimming brings it to 17 MB. Measured across the 0.13.1 beta
  builds, that took the installed footprint from 342 MB to 286 MB and the `.rpm`
  from 102 MB to 83 MB — a before/after within this release's own packaging work,
  not a comparison against 0.13.0, which shipped no CLI at all.

- **Packaged builds are actually exercised.** Every package is now installed,
  extracted, and run in a container before it can be uploaded, including a
  not-pre-seeded `.deb` container and a GUI probe — which is how a packaged-app
  boot abort was caught: bundled PortAudio links against `libjack`/`libasound`,
  present on a desktop and absent in a bare container, and the resulting
  `DllNotFoundException` escaped a view-model constructor. Both entry points are
  tolerant now, and the packages declare the libraries.

- **CI and release safety.** The CLI test suite runs in PR CI and in the release
  workflow (it used to be compiled and never executed), plugin-tag releases are
  gated on tests, plugin publication is a draft-first resumable transaction so a
  late registry failure can't strand a half-published release, SDK/runner/test
  package versions are pinned for reproducible validation, and test
  synchronization is bounded with CI hang budgets. A new integration-test layer
  exercises real orchestrator composition through the full DI lifecycle.

- **Code quality.** ReSharper inspections are at zero across the solution and the
  plugin tree, the CA analyzer findings are cleared, and the CodeQL configuration
  no longer runs maintainability rules that only fire on settled style.

- **Upstream sync.** This release merges the first upstream sync from the
  Windows/macOS project (260 commits), preserving the Linux implementations. Its
  net effect on the Linux tree is small — mostly translation, sync, and export
  helpers.

## Notes

- All new interface strings are translated across **English, German, Spanish,
  and Russian**.
- **The CLI no longer accepts `--port`.** It connects over the discovered Unix
  socket only. The bearer-authenticated TCP endpoint is unchanged, so `curl`
  scripts keep working — with one exception below.
- **`task` and `response_format` are now validated over HTTP too.** An
  unrecognized value returns `400` naming the allowed values; it used to fall
  back silently to `transcribe` / `json`. Scripts relying on that fallback need
  updating.
- **Check saved language selections.** Engines now declare whether they accept
  automatic detection, an explicit language, or both, and a request they can't
  honour is refused instead of quietly reinterpreted. Auto is refused by Google
  Cloud STT and Speechmatics; an explicit language is refused by Cloudflare ASR
  and the non-Canary sherpa-onnx models (Parakeet). Previously those settings
  were ignored — Google, for instance, transcribed Auto as if you had chosen
  English.
- **The socket fallback path moved.** Without a usable `XDG_RUNTIME_DIR`, the
  control and API sockets now live under `Runtime/` in the app's data directory
  rather than `/tmp/typewhisper-$UID`. Integrations that hard-code the old path
  should read the socket path from the discovery file instead.
- Existing plugin secrets and API keys migrate automatically on first start. If
  a value can't be decrypted you get a notice naming how many are affected;
  re-enter those secrets and the migration is retried on the next start. Back up
  before upgrading if you have many provider credentials configured.
- The old `typewhisper` CLI launcher is retired in favour of
  `typewhisper-cli`. Aliases pointing at the old name need updating.
- Follow-ups discovered during the fix run largely landed in this release too:
  `/dev/input` is now opened non-blocking and woken through `poll`/`eventfd`, a
  session mid-recording suppresses a predecessor's window re-activation, and
  readback language is resolved from the effective post-processing language with
  a translation-capability-gated flag. The known residual is narrow — an
  activation landing inside the start-cue interval, before capture opens, is
  still missed. Remaining items are tracked in `docs/code-audit/CODE-AUDIT.md`;
  note that its checkboxes lag the code.
