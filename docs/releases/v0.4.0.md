# TypeWhisper Linux v0.4.0

TypeWhisper Linux 0.4.0 brings dictation to Wayland with an `evdev` global
hotkey backend and `ydotool` text insertion, lands a full single-instance CLI
over a Unix socket, ships a complete Linux release pipeline that produces
`.tar.gz`, AppImage, `.deb`, and `.rpm` packages, and tightens IPC,
configuration, plugin lifecycles, rendering, and desktop-integration behavior
across the app.

## New Features

- Added Wayland global hotkeys via an `evdev` backend, with the shortcut
  backend abstracted behind `IGlobalShortcutBackend`.
- Added Wayland text insertion via `ydotool`, including a setup/diagnostics UI
  (experimental; not yet verified on Hyprland and other compositors).
- Added Wayland active-window and URL detection.
- Added a Shortcuts settings panel with per-desktop shortcut writers,
  auto-setup, and a desktop-portal backend (stub).
- Added a full command-line interface with single-instance control over a Unix
  socket, subcommands, and a JSON control protocol.
- Added settings backup and restore.
- Added the Linux plugin data directory and per-plugin collection settings.
- Added a "close to tray" toggle that is gated on whether a real system tray
  is actually present (detected via a D-Bus probe at startup).
- Added a configurable dictation overlay with selectable Indicator, Waveform,
  and Text widgets, including a live audio-level waveform visualization with
  perceptual scaling and a settings preview.
- Added boot-time startup tracing (`BootTrace`) that logs timestamped stages
  through `Program` and `App` startup for diagnosing slow launches.
- Added a `ProcessPriority` service that resets `nice`/`ionice` to defaults
  on startup so the app isn't pinned to a throttled scheduling class by
  GNOME or systemd's launcher behavior.
- Added a `noSpeechThreshold` setting to the whisper.cpp plugin (default
  `0.6`) so silent segments can be filtered to reduce hallucinated phrases.
- Added a complete Linux release pipeline: `pr-ci-linux.yml`,
  `package-dry-run-linux.yml`, and `release-linux.yml` workflows plus a
  `scripts/build-linux-packages.sh` script that produces a portable
  `tar.gz`, an AppImage, a `.deb`, and an `.rpm` for each tagged release.
- Added per-release changelog files under `docs/releases/` (replacing the
  monolithic `CHANGELOG.md`) and surfaced the full semantic informational
  version, including any pre-release suffix, in the About section.

## Improvements

- Switched to atomic configuration writes and improved application logging.
- Extended atomic, revert-on-failure saves across the Profile,
  Script-collection, Webhook-collection, Dictionary, History, OpenAI Vector
  Memory, and Error-log stores so a failed write can't leave a half-updated
  file on disk.
- Hardened IPC / control-socket path security; the socket directory's
  permissions and ownership are now verified at startup and the app refuses
  to bind to an insecure directory.
- Made Wayland keyboard discovery more robust by probing devices via `ioctl`
  instead of relying on `by-path` symlinks, and by excluding `ydotool`'s own
  virtual device from the candidate list.
- Hardened `ydotool` systemd-user-unit management: setup now marks ownership
  of units it installs and refuses to remove units it didn't install, skips
  the udev rule when `/dev/uinput` is already accessible directly, and
  resolves binary paths and UIDs explicitly.
- Made the Avalonia rendering mode session-aware: native X11 sessions prefer
  GLX (so the dictation overlay's transparency works), while XWayland and
  Wayland sessions prefer EGL (to avoid per-frame GLX exceptions on Mesa),
  with software as the universal fallback. The two harmless log spams from
  this path (the XSMP startup warning and the per-frame GLX
  `SynchronizationLockException`) are now filtered out via dedicated log
  sinks.
- Switched the Linux app to build an `IServiceProvider` directly instead of
  going through `IHost`, shortening startup and dropping the
  `Microsoft.Extensions.Hosting` dependency.
- Made service shutdown asynchronous (`Services.DisposeAsync`) and moved
  disposal into a `finally` block so resources are released cleanly on
  every exit path, including early exits and exceptions.
- Bounded the WebSocket close handshake with a timeout and `Abort` fallback
  in the Deepgram, ElevenLabs, and AssemblyAI streaming sessions.
- Tightened Deepgram URL construction to escape user-supplied model and
  language values.
- Reinforced the Supertonic TTS plugin's disposal path so an in-flight asset
  download can't be torn down mid-write.
- Reinforced the Gemma local plugin: a background auto-load can't repopulate
  weights after the plugin has been unloaded; a load is aborted if the
  selected model is cleared or switched while the inference lock is being
  awaited; a stale persisted model selection is cleared when the referenced
  model is no longer available; and the LLama context is loaded after the
  weights so resources dispose cleanly on failure.
- Serialized Sherpa ONNX compute-backend changes under a lock so concurrent
  model load/unload no longer races, and per-invocation temp files are used
  for downloads so two concurrent downloads can't clobber each other.
- Made the whisper.cpp acceleration preference truthful — the UI no longer
  reports "Preparing CUDA" when the backend swap is refused. The compute
  backend configuration path is now async end-to-end. whisper.cpp model
  file replacement is also atomic now (`File.Move` with overwrite) so a
  crash mid-swap can't leave a partial file on disk.
- Improved ChatGPT login validation in the OpenAI plugin so revoked or
  expired-beyond-refresh credentials surface a clear error instead of a stale
  "connected" message.
- Marked German localization for the xAI and OpenAI plugins with proper
  umlauts and a more natural reasoning-effort label.
- Clarified KDE shortcut-writer messages so they actually walk the user
  through restarting the KGlobalAccel daemon.
- Refactored the dictation-overlay feedback timer so it can re-arm while
  still visible — quick repeat actions stay reflected instead of getting
  swallowed by the running timer.
- Sherpa ONNX model downloads now use a per-invocation temp file with
  cleanup on failure, so two concurrent downloads can't clobber each other.
- Error reports now record the actual OS platform string instead of a
  hardcoded `"Linux"`.
- Trimmed API keys on load and on use in the OpenAI, OpenAI Vector Memory,
  Claude, and Gladia plugins so legacy keys with stray whitespace stop
  breaking the `Authorization` header.
- Scrubbed sensitive payloads from plugin error logs (Cloudflare ASR,
  Speechmatics, Gladia, Linear, OpenAI Vector Memory): raw API error bodies
  are logged separately from exceptions, and Linear additionally records a
  payload fingerprint instead of the user-data-bearing GraphQL body.
- Made the Webhook plugin safe under concurrent access: dedicated locks
  guard the observable collection and the save path, a `SnapshotWebhooks()`
  helper gives callers a safe enumeration, the underlying `HttpClient` is
  disposed on deactivation, and a save is refused if the initial load
  failed (so a transient I/O error can't silently clobber a valid config).
- Hardened the WAV encoder: only 16-bit PCM is accepted, and `sampleRate`
  and `channels` are validated to prevent malformed WAV files.
- Made `AudioRecordingService` survive pause/resume cleanly: the capture
  sample rate is no longer reset on resume (which previously caused
  unnecessary resampling and corruption), and the negotiated sample rate
  and resampled output size are now logged for diagnosis.
- Made the Script plugin robust against wedged child processes: stdout/
  stderr are read before stdin is written (avoiding a pipe-buffer deadlock),
  every stdin/stdout/stderr operation has a 5-second cancellation timeout,
  the config file is written atomically with a temp file + `File.Replace`,
  and the child process is now killed if the caller cancels the run.
- Made `DictionaryService` thread-safe and predictable: `cacheLoaded` uses
  volatile reads/writes; `Regex.Replace` uses the `MatchEvaluator` overload
  so replacement strings containing `$` sequences are taken literally;
  usage counts are batched and persisted once at the end of a run; and
  empty-`Original` entries are filtered before matching.
- Pinned `appimagetool` to `v1.9.1` and verified its checksum during the
  AppImage build for supply-chain safety, and required both `wget` and
  `sha256sum` to be present before attempting the build.
- Locked down CI: all `actions/checkout` steps now use
  `persist-credentials: false`, the plugin smoke-test workflow uses a flat
  string path matrix, and the packaging step prunes non-`linux-x64` native
  runtimes from the published output to keep packages lean.
- Propagated the host's version into plugins at deploy time and cleared
  stale plugin builds before redeploying so a version mismatch can't
  surface as a load failure on a freshly installed app.
- Added `ProviderProcessRunner` argv-style argument passing for the
  active-window providers and used it from the KWin provider.

## Fixes

- Fixed memory leaks in plugins, core services, and event-handler wiring.
- Fixed WebSocket close-handshake handling in the AssemblyAI streaming
  session.
- Fixed thread safety in the local Gemma plugin.
- Fixed configuration-loading error handling and `ydotool` process cleanup.
- Fixed a toggle-gate race that blocked starting a new dictation immediately
  after the previous one finished.
- Fixed an unhandled `OperationCanceledException` in the GNOME Shell
  active-window provider.
- Fixed the Script plugin so a caller-cancelled run kills the child process
  instead of leaking it, and so corrupt `scripts.json` files are no longer
  silently overwritten when the settings UI saves before the plugin
  activates.
- Fixed the Qwen3 STT plugin so it fails fast on translation requests instead
  of silently ignoring the flag.
- Fixed Speechmatics language handling so `"AUTO"` and `"Auto"` resolve the
  same as `"auto"`.
- Fixed Supertonic TTS so the language tag prefix is normalized to lower
  case, keeping tokenization deterministic across mixed-case callers.
- Fixed several HTTP response leaks in the OpenAI plugin (ChatGPT, OAuth, and
  Responses clients) and across the Cloudflare ASR, Groq, Linear, Sherpa
  ONNX, Speechmatics, and SuppressGlxRenderExceptionLogSink paths by moving
  responses into `using` declarations.
- Fixed SSE parsing in the ChatGPT client so a single malformed frame no
  longer aborts the whole stream.
- Fixed plugins whose display name began with whitespace rendering
  misaligned in the Plugins section grid.
- Fixed the OpenAI Vector Memory plugin treating a whitespace-only API key
  as configured, and made it fail loudly (instead of silently dropping data)
  when the on-disk vector memory file fails to load.
- Fixed the Linear plugin silently swallowing malformed GraphQL responses;
  parse failures are now logged with context.
- Fixed the Soniox plugin's transcript JSON parsing so a single
  unexpectedly-shaped frame no longer breaks transcript extraction.
- Fixed dictionary corrections being applied for entries with empty
  `Original` strings, and corrected regex boundary handling around non-word
  characters.
- Fixed `TextDiffService` to use `TrimEnd()` instead of `Trim()` so leading
  punctuation in a diff segment is preserved, and corrected nested-loop
  brace handling.
- Fixed `SnippetService` crashing on a `null` profile-ID list by treating
  `null` the same as empty (global match).
- Fixed `ProfileService` allowing a disabled profile to be force-selected.
- Fixed `ShortcutsSectionViewModel` losing the UI sync context on awaits so
  property-change notifications now reach the UI thread.
- Fixed `AtomicFileWriter` accepting an invalid target directory.
- Fixed the Sherpa ONNX plugin so WAV chunks with overlong size fields can't
  trigger overflow or out-of-bounds reads.
- Fixed the whisper.cpp plugin so an invalid `noSpeechThreshold` is no
  longer silently persisted — invalid values now surface a validation
  error in the settings UI.
- Fixed tray icon initialization on startup and made tray hide/show behavior
  consistent across compositors.

## Removed

- Removed the GraniteSpeech plugin in its entirety (source, scripts,
  requirements, manifest, project, publish-workflow entries, and `.gitignore`
  references).
- Removed Windows-specific UI and services that no longer apply to the Linux
  build.
- Removed outdated Wayland global-shortcut design documents.
- Removed the legacy monolithic `CHANGELOG.md` in favor of per-release files
  under `docs/releases/`.
- Removed the legacy `issue-to-discord.yml` workflow.
