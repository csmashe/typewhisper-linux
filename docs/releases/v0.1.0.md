# TypeWhisper Linux v0.1.0

TypeWhisper Linux 0.1.0 is the initial Linux port of TypeWhisper, converted
from the Windows / WPF edition. It establishes the full dictation loop, a
cross-platform plugin system, and the application shell on Linux.

## New Features

- Added the initial Linux port of TypeWhisper, built on Avalonia in place of the
  Windows-only WPF UI.
- Added the end-to-end dictation loop covering audio capture, transcription,
  and text insertion at the cursor.
- Added the cross-platform plugin SDK (decoupled from WPF), with a Linux plugin
  loader, plugin manager, and model manager.
- Added the application shell with sidebar navigation, settings sections, and a
  first-run onboarding wizard.
- Added system-tray integration with minimize-to-tray and a `CloseToTray`
  preference.
- Added Push-to-Talk and Hybrid hotkey modes alongside toggle dictation.
- Added audio ducking and media-pause services that quiet other audio while
  dictating.
- Added LLM provider support and prompt actions for post-processing
  transcripts.
- Added a translation service with a UI for choosing a target language.
- Added history, dictionary, and snippet application so dashboard statistics
  populate.
- Added the plugin settings-provider abstraction with generated settings UI,
  plugin categorization, and async loading.

## Fixes

- Fixed plugin discovery so it no longer loads duplicate SDK assemblies.
- Fixed application exit so teardown is ordered and timeout-guarded instead of
  hanging.
- Fixed a blank-audio race in Push-to-Talk and Hybrid modes.
