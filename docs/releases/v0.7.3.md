# TypeWhisper Linux v0.7.3

TypeWhisper Linux 0.7.3 is a KDE Plasma fix release. It closes two gaps left
over from the 0.7.2 onboarding work, both on KDE Wayland: active-window
detection now has a one-click setup so per-app profiles and usage stats actually
work, and model downloads show a real progress bar instead of jumping straight
from 0% to 100%. KDE Plasma 6 (Wayland) is now a tested setup.

## Improvements

- **KDE active-window detection setup.** On KDE Plasma Wayland the setup
  checklist now offers a one-click install of `kdotool`, which TypeWhisper uses
  to read the focused window. KWin under Wayland exposes no unprivileged
  active-window API, so without it per-app profile matching and the dashboard's
  app attribution silently did nothing — and nothing in setup pointed that out.
  Like the other package installs it's a single admin prompt with a copyable
  fallback command. The item only appears on KDE Wayland: KDE X11 already works
  through xdotool, and GNOME keeps its own Window Calls step.

## Fixes

- Model-download progress now animates as a real progress bar that fills as the
  file downloads, on both the onboarding model picker and the Engine settings
  page. Previously the status jumped 0% → 100% with nothing in between.
- The whisper.cpp engine now reports incremental download progress — the root
  cause behind that jump. The download stream isn't seekable, so its total size
  was unknown and no intermediate progress was ever emitted; it now falls back to
  the model's known size as the denominator, so every chunk advances the bar.

## Not Ported From Windows

- Windows release channels and Velopack update-channel controls are not part of
  this Linux branch; the Linux app checks GitHub Releases for updates but installs
  them manually.
- Windows-specific workflow automation and packaging changes remain Windows-only.
