# TypeWhisper Linux v0.19.0

TypeWhisper Linux 0.19.0 speaks two more languages and adds a set of new
providers and local models. **The interface is now available in Japanese
and Simplified Chinese**, and it switches language live, including plugin
settings, without a restart. New providers: **GitHub Copilot** for prompts,
**Cohere Transcribe**, **Mistral text processing** on the Voxtral plugin,
and **Smallest AI Lightning text-to-speech**. New local models: **Qwen3-ASR
0.6B and 1.7B** in the Sherpa-ONNX plugin, and **Vulkan GPU acceleration**
for whisper.cpp.

New in the app: a saved **System, Light or Dark theme**, a **floating live
text window**, **local model cards** with download progress, a **language
picker that lists every language the engine supports** (99 for whisper.cpp,
100 for Large V3), **Delete All Data** with restart-safe cleanup,
**dictionary alias suggestions** from a local LLM (including a local
Ollama), **dictionary import from Handy and Wispr Flow**, **Script Runner
templates** with a test run, a **shortcut recorder**, a **Default LLM**
selector, **live cleanup while you speak** (opt-in), `typewhisper --page` to
open a settings page, and a `POST /v1/text/process` API route. The setup
wizard now **defaults to Parakeet Ultra 0.6B**.

Most provider and model work was ported and adapted from upstream
TypeWhisper. The ChatGPT token-sharing sign-in, shortcut recorder, Vulkan
acceleration, OpenRouter catalog refresh, global cleanup provider, text
processing route, live cleanup and the headless UI render checks were
contributed by [@jayshah5696](https://github.com/jayshah5696).

**Upgrade notes:** the deb and rpm packages now depend on the system SQLite
library (for the Wispr Flow import). Japanese and Chinese need a CJK font;
the packages suggest Noto Sans CJK, which Ubuntu, Fedora Workstation and
Debian desktops already install. On **Auto**, a Traditional Chinese system
(zh-TW, zh-HK, zh-MO) stays in English rather than switching to Simplified
Chinese. ChatGPT users must **sign in again** (the sign-in flow changed).
Several bundled plugins now require this version of the app (see
[Plugin SDK](#plugin-sdk)).

## New Features

### Interface

- **Japanese and Simplified Chinese.** **General → Interface Language** adds
  **日本語** and **简体中文** beside English, German, Spanish and Russian, for
  the app and every bundled plugin. Auto picks them on a Japanese or
  Simplified Chinese system. Traditional Chinese systems stay in English on
  Auto, since only a Simplified catalog ships; you can still choose 简体中文.
  Rendering needs a CJK font such as Noto Sans CJK.
- **Live language switching that reaches everything.** Changing the
  interface language now also updates status lines that were computed once
  (the CLI install and local API status on General, the browser status on
  Profiles, the Plugins summary and cards, the spoken-feedback provider on
  Advanced) and plugin settings and descriptions, without a restart. The
  local API status and the Linux system voice name were English in every
  language and are now translated.
- **Theme.** **Appearance → Theme** offers **System** (follows the desktop's
  light or dark setting), **Light** and **Dark** (the default, so nothing
  changes). It applies immediately to every window, dialog and menu. The
  recording overlay and the correction toast stay dark.
- **Floating live text.** **Appearance → Live text → Live text position**
  can show the text you are dictating **In the overlay** (as before) or in a
  **Floating window** you can move and resize. Its position and size are
  saved and kept on screen.
- **Open a settings page from the command line.** `typewhisper --page
  <page>` opens a page (dashboard, dictation, shortcuts, text-insertion,
  file-transcription, recorder, history, dictionary, snippets, profiles,
  prompts, plugins, general, appearance, advanced, about) and starts the app
  if needed. `--page plugin:<id>` jumps to one plugin and opens its settings.
- **Accessibility.** Settings controls and the sidebar have screen-reader
  names, labels wrap in narrow windows, and the build renders every Settings
  section headlessly in each language and window size, failing on clipped
  text, raw keys, wrong-language text or unnamed controls.
- **Screen readers hear labels, not code** (#180). Drop-down values read
  as their visible label instead of internal names, list rows (Profiles,
  History, the palettes, the file queue, import review) are named from what
  they show, and icon buttons, slider and spin-box parts, plugin switches
  ("Enabled: <plugin>"), plugin expanders ("Show/Hide <plugin> settings"),
  plugin setting fields and profile chips have real names in every
  language. The render check now also fails on names that look like code.
- **The profile editor fits narrow windows** (#181). Each setting's value
  sits under its label at full width, the app and URL fields stack their
  capture button, the profile list shrinks with the window, and long labels
  and selected values wrap instead of clipping. A render test opens the
  editor in every language and window size.

### Dictation and local models

- **Local model cards.** **Dictation → Local models** shows a card per
  whisper.cpp and Sherpa-ONNX model with its size, engine and status
  (Active, Downloaded, Recommended, Downloading, Loading, Failed). A card can
  download a model without switching to it (dictation keeps working),
  cancel, switch dictation to it, or remove it. Progress survives leaving
  the page. Downloaded, selected, busy and recommended models are listed;
  **Show all** lists the rest. Model storage cannot be moved during a
  download.
- **Every language the engine supports.** The spoken-language picker lists
  every language the active engine declares, by native name (for example
  Українська or English (United States)), instead of a fixed list of 18.
  whisper.cpp now declares Whisper's 99 languages, and Large V3 and Large V3
  Turbo also Cantonese; English-only `.en` models keep accepting any saved
  choice. Engines that declare no list keep the 18 common languages, and a
  saved language stays selectable when no engine is active. Bashkir and
  Occitan get names even on older ICU versions (Ubuntu 22.04/24.04,
  Debian 12, Fedora 42) that lack them.
- **Qwen3-ASR 0.6B and 1.7B (local).** The Sherpa-ONNX plugin adds
  Qwen3-ASR 0.6B (about 990 MB) and 1.7B (about 2.4 GB), each file pinned by
  size and SHA-256. Both take any of 30 languages; 0.6B can also detect the
  language, 1.7B needs it set. No translation or token timings. Qwen runs on
  the CPU, also when CUDA is selected. The first CUDA use after updating
  downloads the new Sherpa-ONNX GPU runtime (sherpa-onnx 1.13.8).
- **Vulkan acceleration for whisper.cpp.** **Dictation → Local model
  acceleration** adds **Vulkan** for GPUs with Vulkan drivers (AMD, Intel and
  NVIDIA). Settings
  show whether Vulkan is available before a model loads and the active
  backend after; it falls back to the CPU when Vulkan is unavailable.
  Switching between CUDA and Vulkan needs a restart.
- **Parakeet Ultra by default.** The setup wizard now preselects **Parakeet
  Ultra 0.6B** when no model is saved and the interface language is one of
  its 25 European languages; otherwise it picks a recommended local model
  (whisper.cpp Base). whisper.cpp now recommends only **Base**.
- **Live cleanup while you speak (opt-in).** **Dictation → Clean drafts while
  recording** sends revisable drafts to your AI provider during pauses and
  reuses a matching result when you stop. It needs live transcription and
  Medium or High cleanup, and cloud providers may charge per draft. It is
  unavailable while a text processor such as Filler Words is enabled, and
  says which.

### Dictionary

- **Suggest aliases.** **Dictionary → Suggest aliases…** asks a local LLM how
  a term might be misheard. Suggestions arrive unchecked; **Save** adds the
  checked ones as corrections. Only local models are used: Gemma (Local), or
  an OpenAI-compatible server on this machine (localhost or a loopback
  address, such as Ollama). Ollama's `:cloud` models are hidden, and a
  loopback server's requests never follow redirects or use a proxy.
- **Import from Handy and Wispr Flow.** **Dictionary → Import** adds **From
  Handy…** (custom words, from
  `~/.local/share/com.pais.handy/settings_store.json` or a picked file) and
  **From Wispr Flow…** (pick a `flow.sqlite` copied from Wispr Flow on
  another computer; terms plus phrase-to-spelling corrections). You review
  duplicates and conflicts first; nothing is written until **Add**, and a
  dictionary changed meanwhile stops the import.
- **Dictionary terms for xAI and Reson8.** xAI receives your terms as
  `keyterm` values (batch and live) and Reson8 as phrases, with language
  hints.

### Providers and plugins

- **GitHub Copilot (new plugin).** Use your GitHub Copilot subscription for
  prompts and cleanup. **Download Copilot runtime** fetches about 51 MB once
  (verified, kept in the plugin folder). Sign in with `npx -y
  @github/copilot` and `/login` (a `gh` login alone is not enough), then
  **Refresh accounts**. A default account plus extra profiles, each bound to
  one account with no fallback.
- **ChatGPT sign-in rewritten.** The OpenAI plugin's **Sign in with
  ChatGPT** now uses OpenAI's documented token-sharing flow: models are
  discovered and filtered by your plan, with clear messages for plan
  limits and unsupported features. Sign in again after updating.
- **Cohere Transcribe.** The Cohere plugin adds cloud transcription
  (`cohere-transcribe-03-2026`) beside Command, with an explicit language
  (14 languages; Auto is not supported) and a 25 MB upload limit.
- **Mistral text processing.** The Voxtral plugin adds Mistral chat models
  for prompts and cleanup, with an account model catalog separate from the
  transcription models, using the same key.
- **Smallest AI Lightning text-to-speech.** The Smallest AI plugin (renamed
  from Smallest AI Pulse) adds a voice for **Spoken feedback**: voices load
  after **Validate** or **Refresh voices**, speed 0.5–2×, up to 8,000
  characters, 12 MB and two minutes.
- **OpenRouter catalog refresh.** A **Refresh** button loads OpenRouter's LLM
  and transcription models. Opening a settings panel no longer fetches or
  saves anything.
- **Script Runner templates.** **Add template** inserts a ready bash script
  (disabled until you save), and **Test script** runs the unsaved draft
  against sample text (five-second limit, 1 MB output).
- **Default LLM.** **Prompts → Default LLM (cleanup and prompts)** chooses
  the provider for Medium and High cleanup, prompt actions and spoken
  commands without an override. Automatic names the provider it will use.
- **Shortcut recorder.** **Shortcuts → Record keys** captures a shortcut by
  pressing it, with cancel, conflict and unsupported-key messages.

### Data and automation

- **Delete All Data.** **About → Delete All Data…** removes everything
  TypeWhisper stores (optionally also downloaded models and GPU runtimes)
  after confirmation. Work in progress is stopped, then TypeWhisper
  restarts, deletes the data as it starts and opens setup; an interrupted
  deletion finishes at the following start. Installed files and plugins stay.
- **`POST /v1/text/process`.** Runs transcript text through profile matching
  and the dictation pipeline without recording or inserting, and returns
  the final and raw text, the profile, engine and per-step timings. It does
  not count toward usage statistics.

## Fixes

- **Setup wizard:** the model list is locked while the chosen model
  downloads, so the wizard can no longer show one model while it loads and
  saves another.
- **Authenticated CLIs:** the Automatic installation option now says it uses
  the only installation found (with several, you are asked to choose).
- **API bearer token:** a legacy 64-character token is kept during secret
  migration instead of being rotated.
- **Sherpa-ONNX** provider name read "Lokal (sherpa-onnx)" in English; it
  now reads "Local (sherpa-onnx)".
- API-key validation responses are disposed in AssemblyAI, Cohere,
  Deepgram, Groq and OpenAI.

## Plugin SDK

All additions are optional, and plugins built against the previous SDK keep
loading.

- `IPluginCollectionItemTester` and `PluginCollectionDefinition.Templates` /
  `ItemTest` (`PluginCollectionTemplate`, `PluginCollectionItemTest`,
  `PluginCollectionItemTestResult`): a settings collection can offer
  templates and a draft test run.
- `ILlmProviderEndpoint.LlmEndpoint` and `Helpers.LoopbackEndpoint`: an LLM
  role reports its endpoint so the host can recognize a server on this
  machine.
- `TranscriptionAccelerationBackend.Vulkan`,
  `TranscriptionAccelerationPreference.Vulkan` and `VulkanAvailability`.
- `LlmResponseTruncationGuard` also recognizes Mistral's `model_length`
  finish reason.
- `PluginSettingOption` and `PluginCollectionTemplate` `ToString()` return
  their label, so screen readers announce it (#180). Binary compatible; no
  host floor.
- `minHostVersion`: every bundled plugin declares 0.19.0, the SDK it is
  built against.
- Bundled plugin versions: OpenAI 1.4.0; Sherpa-ONNX, OpenRouter, Reson8
  and xAI 1.2.0; Cohere, OpenAI Compatible, Script Runner, Smallest AI,
  Voxtral and whisper.cpp 1.1.0; AssemblyAI 1.2.1; Groq 1.0.6; Deepgram
  1.0.3; GitHub Copilot 1.0.0 (new). Every other bundled plugin gets a
  patch bump for its Japanese and Simplified Chinese catalogs.

## Under the Hood

- Every bundled plugin ships `ja.json` and `zh.json`; catalog tests now
  require every app and plugin catalog to cover every English key with the
  same placeholders.
- The UI render checks run in all six languages; CI installs
  `fonts-noto-cjk` for the Japanese and Chinese runs.
- The deb and rpm packages depend on the system SQLite library and suggest
  a Noto CJK font. The AppImage and tarball use the system SQLite if
  present.
